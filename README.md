# Cupcake-Collector
High school lab

Lab #2: Cupcake Collector
Now let's move from geometric circles to an actual game character.
In most 2D games, characters and objects are represented using sprites.
A sprite is a 2D image used to represent a character, enemy, collectible, or other game object.
Your Goal
Create a simple platform game in which a cute character:
moves left and right;
jumps onto platforms;
collects cupcakes;
earns points for each cupcake collected.
